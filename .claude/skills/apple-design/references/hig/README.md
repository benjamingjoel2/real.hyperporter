# Apple HIG corpus

53 documents adapted from [Apple's Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/),
sourced from [dickwu/apple-design-skill](https://github.com/dickwu/apple-design-skill) and kept
verbatim so they can be cited accurately.

They are written for mobile and desktop apps. **Read `../web/` first** — it translates these
principles into CSS, HTML and browser conventions. Come here for the original wording, for
citation, or for a topic with no web file.

Each file keeps a `> Source:` link back to the corresponding HIG page.
